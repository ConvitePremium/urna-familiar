# Urna Familiar — versão com assets

Envie `index.html` e a pasta `assets` para a raiz do seu repositório GitHub.

## Seus arquivos
Coloque em `assets/`:
- `lula.webp` — imagem para o número 13
- `bolsonaro.webp` — imagem para o número 22
- `jesus.webp` — imagem para o número 33
- `urna-final.mp3` — áudio real de confirmação da urna

Os nomes devem ser exatamente esses, com letras minúsculas. Não é necessário enviar suas imagens ou MP3 aqui; você mesmo pode incluí-los no GitHub.

## Funcionamento
Ao digitar um número válido, o retrato correspondente aparece ampliado na tela. Ao confirmar, o navegador tenta reproduzir o MP3. Se não estiver disponível, usa o som alternativo. A apuração mostra os votos e nomes de cada participante. Os votos ficam no armazenamento local do navegador.

## GitHub Pages
Settings > Pages > Deploy from a branch > main > /(root).
